# baby-yoda-project.brunacarolline
Ce projet propose une illustration de Baby Yoda entièrement conçue avec HTML et CSS. Il démontre l'utilisation créative des propriétés CSS, telles que le positionnement, les gradients, les formes géométriques, les pseudo-éléments (::before, ::after) et les bordures, pour construire un personnage visuellement reconnaissable.
